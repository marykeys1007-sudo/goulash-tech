# Фотографии блога

Добавьте сюда три отдельные фотографии (не коллаж), горизонтальные 16:9, желательно 1600×900 WebP:

- `technician.webp` — выездной специалист в рабочей одежде диагностирует оборудование на объекте клиента.
- `dispatch-team.webp` — небольшая диспетчерская команда планирует заявки и маршруты за рабочим столом.
- `analytics.webp` — крупный план ноутбука с абстрактной аналитикой и картой маршрутов.

Единый редакционный фотореалистичный стиль, естественный свет, нейтральные тёмные/серые/белые оттенки с небольшими бирюзовыми деталями. Без логотипов, читаемого случайного текста, водяных знаков, кислотных цветов и киберпанк-декора.

Если файлов пока нет, компонент автоматически показывает брендовый placeholder.
