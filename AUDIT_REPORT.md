# Аудит и внесённые исправления GOULASH.TECH

## Проверенный источник

Проверен переданный пользователем `GOULASH-TECH-project.zip` и мастер-промт из приложенного текстового файла. Существующая архитектура и логика использованы как основа; проект не переписывался с нуля.

## Критические проблемы исходного ZIP

1. **Нарушена структура файлов.** `index.html` ссылался на `/src/main.js`, а `main.js` импортировал `src/components`, `src/data`, `src/styles`, `src/utils`, но все исходные модули лежали в корне архива. Исправлено: файлы разложены в ожидаемые каталоги `src/`.
2. **Отсутствовали ожидаемые статические пути.** Блог запрашивал `/images/blog/master-service.png`, `team.png`, `computer.png`, которых не было в `public/images/blog`. Из исходных фотографий созданы оптимизированные WebP-файлы и размещены по нужным путям.
3. **Не было отдельного видеоблока.** Добавлен самостоятельный раздел 16:9 после Hero. Пока реального видео нет, отображается постер с явным статусом; не создаётся сломанный плеер. Для подключения MP4 предусмотрена одна константа.
4. **Не было семиэтапной визуализации операционного контура.** Добавлена отдельная последовательность из семи этапов в секцию системы; существующий четырёхэтапный блок «Как это работает» сохранён.
5. **Пиксельная анимация была локальной.** Существующий pointer trail в секции системы сохранён. Дополнительно добавлен один общий canvas-слой, который рисует сдержанную пиксельную волну у границ секций; он активен только когда граница находится в окне просмотра.
6. **3D-наклон Network Live был сильнее заданного в мастер-промте.** Амплитуда ограничена примерно 5°, добавлен небольшой внутренний параллакс карты; эффект по-прежнему отключается на touch и при `prefers-reduced-motion`.
7. **Вопросы FAQ содержали редакционные заглушки `[?]`.** Они заменены нейтральными ответами, опирающимися на описанную концепцию, без обещаний сроков или неподтверждённых гарантий.
8. **Ссылки блога вели на тот же блок и блокировались JS.** Заменены на рабочий переход к форме — «Обсудить тему».
9. **Логотип дублировался отдельным SVG в коде.** Компонент теперь использует оригинальный `favicon.svg` из архива как общий брендовый знак.
10. **Персоны выглядели как отзывы и содержали неподтверждённые точные масштабы.** Заменены на типовые задачи без псевдоцитат и вымышленных числовых показателей.
11. **Палитра была ближе к чёрно-бирюзовой.** Токены приведены к холодной сине-голубой палитре из мастер-промта: `#080D18`, `#101A2A`, `#142238`, `#258BD0`, `#55BDF0`.

## Что сохранено без перестройки

- Vite + Vanilla JavaScript.
- Существующие секции, их порядок и компоненты.
- Network Live с SVG-маршрутом и движущимся маркером.
- Демонстрационная панель: заявки, карта, специалисты, аналитика, сценарий, фильтры и назначение.
- Четырёхэтапный процесс «Как это работает».
- Шесть карточек возможностей.
- Сегменты, калькулятор, FAQ, контактная форма и футер.
- Навигация без тарифного пункта и без публичного блока тарифов.
- Существующие тексты и условные демонстрационные данные, кроме явно отмеченных редакционных заглушек и формулировки о «деньгах», не подтверждённой составом модулей.

## Функциональные ограничения, которые намеренно не маскировались

- Форма сохраняет данные только в `localStorage`; серверного endpoint, CRM и Telegram-уведомлений в архиве нет.
- Network Live и демо-карта — демонстрационные схемы, не реальная карта/GPS.
- Все заявки, адреса, специалисты и KPI демо условные.
- Калькулятор использует условное допущение 15%, которое раскрыто в интерфейсе.
- Отдельные страницы статей не предоставлены; CTA карточек ведут к форме обсуждения.
- Рекламное видео не было приложено; слот готов, но плеер не активируется до добавления MP4.
- Фотографии исходного архива выглядят как современные рабочие пространства, но не имеют явных маркеров России. Они сохранены и оптимизированы; для однозначно российской визуальной идентичности их следует заменить специально подобранными российскими изображениями.

## Проверки

- Все JS-файлы прошли `node --check`.
- Все относительные JS-импорты проверены на существование.
- Production build не подтверждён: установка зависимостей `npm ci` превысила доступный лимит времени, Vite в результате остался неполным и `npm run build` завершился сообщением `vite: not found`.
- Браузерная проверка кликов и визуальная проверка адаптивности в этой среде не выполнены.

## Следующий обязательный шаг на компьютере

```bash
npm ci
npm run build
npm run dev
```
