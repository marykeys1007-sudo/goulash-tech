# GOULASH.TECH

Лендинг для технологической системы управления выездным сервисом. Проект сохраняет исходный стек **Vite + Vanilla JavaScript** — React/Next.js и дополнительные UI-фреймворки не добавлялись.

## Запуск локально

Требуется Node.js 18+ (рекомендуется актуальная LTS-версия).

```bash
npm ci
npm run dev
```

Vite покажет локальный адрес в терминале (обычно `http://localhost:5173`).

## Production-сборка

```bash
npm run build
npm run preview
```

Готовый сайт собирается в `dist/`.

## Подключение рекламного видео

1. Положите готовый MP4-файл в `public/videos/goulash-brand-film.mp4`.
2. Откройте `src/components/VideoShowcase.js`.
3. Замените `const VIDEO_SRC = '';` на:

```js
const VIDEO_SRC = '/videos/goulash-brand-film.mp4';
```

Пока файл не подключён, сайт показывает аккуратную обложку и подпись о подготовке ролика — не создаёт сломанный плеер. Видео не запускается автоматически; после подключения доступны стандартные controls и полноэкранный режим.

## Изображения

Фотографии для блога уже включены в `public/images/blog/` в WebP. Это предоставленные в исходном архиве изображения, оптимизированные для сайта. Они показывают современную рабочую среду, сервисного специалиста и команду диспетчеризации. Они не содержат явных географических маркеров, поэтому если нужна однозначно узнаваемая российская среда, эти три изображения стоит позднее заменить отдельными российскими фотоматериалами без изменения кода компонента.

## Важные ограничения функциональности

- Интерактивное демо использует условные данные в браузере; это не подключённая production-система диспетчеризации.
- Network Live — демонстрационная SVG-схема маршрута, а не подключённая географическая карта или GPS.
- Форма проверяет поля и сохраняет заявку только в `localStorage` текущего браузера. Серверная отправка, CRM, Telegram и уведомления не подключены.
- Калькулятор показывает условную оценку с допущением 15%, которое отдельно раскрыто рядом с расчётом.
- В блоге пока нет отдельных страниц статей; кнопки карточек ведут к форме обсуждения темы.
- Публичный раздел тарифов удалён из рендера, навигации и контента.

Перед публикацией подключите серверную обработку формы, актуальную политику обработки персональных данных и реальные данные/интеграции, если они входят в фактический продукт.

## Hologram showcase (November 2026)

The audience section now uses the dark Goulash palette with the brand cyan reserved for accents and readable light body copy. Immediately after it, `HologramShowcase.js` adds the technician hologram scene. The supplied neutral hologram is pixel-built on scroll; the scene then crossfades to a smiling hologram variant and continues with a restrained animated pixel shimmer. Both image assets live in `public/images/`. The animation respects `prefers-reduced-motion`; when reduced motion is enabled, the smiling image is shown without the build animation.


## Обновление: голограмма, Bento-блок и фотографии аудиторий

- Голограмма и блок о принципе Goulash.tech объединены в одну адаптивную Bento-композицию.
- Две отрасли — ресторанная доставка и выездной сервис — показаны внутри этой композиции, отдельный повторяющийся блок удалён из порядка рендера.

- Для голограммы сохранён видимый резервный слой исходного изображения под Canvas: если браузер не сможет отрисовать частицы, визуал специалиста всё равно останется видимым.


## Стабилизация демо и голограммы

Демо-панель обновляет только активное содержимое, сохраняя прокрутку списка и фокус поиска. Полоса прокрутки оформлена в фирменных цветах. Логотип в подвале использует тот же квадратный знак, что и верхняя навигация. Голограмма читает изображения из `public/images/`; при невозможности создать Canvas/частицы включается видимый резервный образ, чтобы блок не оставался пустым.
