GOULASH.TECH — восстановление согласованной пиксельной голограммы

Архив собран на базе последнего полного проекта с исправленной валидацией формы.
Десктопный алгоритм голограммы восстановлен из версии, в которой пользователь подтвердил успешную сборку из пикселей и пульсацию.

Десктоп: исходный лимит 9500 частиц, DPR до 1.5, полная частота requestAnimationFrame, реакция на курсор.
Мобильные устройства (ширина до 767px): тот же алгоритм сборки/пульсации, лимит 4200 частиц, DPR 1.0, около 30 FPS, без реакции на курсор.

Валидация формы и остальные файлы последнего полного проекта сохранены.

Заменены только:
- src/utils/hologram.js
- src/styles/hologram.css

Запуск: npm run dev
