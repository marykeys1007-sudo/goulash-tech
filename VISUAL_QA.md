# QA — GOULASH.TECH

## Проверено в этой доработке

- Структура проекта приведена в соответствие с путями импорта Vite.
- Все относительные JS-импорты указывают на существующие файлы.
- Все JS-модули прошли `node --check`.
- Навигация и футер не содержат пункта/ссылки на тарифы.
- Подключены оптимизированные изображения блога.
- Добавлен видеоблок в состоянии постера без несуществующего MP4.
- Добавлена семиэтапная схема операционного цикла.
- Добавлен общий canvas-слой пиксельного перехода с отключением при `prefers-reduced-motion`.
- 3D-наклон ограничен до 5 градусов; на touch и при reduced motion выключается.
- FAQ не содержит редакционных маркеров `[?]`.
- CTA блога ведут к форме, а не на несуществующие статьи.

## Проверки, которые не удалось завершить

- `npm ci --no-audit --no-fund --prefer-offline` превысил лимит времени в среде исполнения.
- После неполной установки `npm run build` не запустился: бинарник Vite отсутствовал (`vite: not found`).
- Браузерная проверка и скриншоты после изменений не выполнялись.

## Локальная проверка перед публикацией

```bash
npm ci
npm run build
npm run dev
```

Затем проверить мобильное меню, якоря, демо-сценарий, назначение мастера, фильтры, периоды аналитики, калькулятор, FAQ, форму, 3D Network Live и пиксельные переходы на 375 / 768 / 1024 / 1440 px.

## Не подключено

- Серверная отправка формы / CRM / Telegram.
- Реальная карта и GPS.
- Реальные данные вместо демонстрационных.
- Финальный MP4 в `public/videos/goulash-brand-film.mp4`.
- Отдельные страницы статей блога.
