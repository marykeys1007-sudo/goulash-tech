# Goulash.tech — объединение бренд-концепций

## Архитектура бренда

Goulash.tech представлена как одна технологическая компания с отраслевыми продуктами, а не как один универсальный сайт для всех клиентов.

- **Ресторанная доставка** — отдельное направление для ресторанов и сетей: цепочка от первого клика и приёма заказа через кухню и маршрутизацию до повторного заказа гостя.
- **Выездной сервис** — отдельное направление для мастеров, бригад и сервисных компаний: цепочка от обращения и диспетчеризации до выезда, закрытия работы и аналитики.

Общий принцип компании — связать все ключевые действия, участников и данные в один управляемый операционный контур. Текущая страница остаётся посвящённой исключительно выездному сервису; ресторанная аудитория не смешивается с её основным оффером.

## Логотип и акцент

- `public/logo.svg` — векторная реконструкция предоставленного пользователем логотипа Goulash.tech.
- `public/favicon.svg` — знак G в фирменном квадрате.
- Фирменный акцент взят из референса: `#00FFFF`.
- Для текста акцента на светлом фоне используется более тёмный оттенок `#007F83` ради читаемого контраста; кнопки, рамки, пиксельные эффекты, индикаторы и активные состояния используют основной циан.

## Изменённые файлы

- `src/utils/icons.js` — общий логотип в шапке и футере.
- `src/components/Sections.js` — добавлен блок общего принципа компании с двумя разными отраслевыми направлениями.
- `src/main.js` — подключён новый блок.
- `src/data/content.js` — навигация и формулировка футера.
- `src/styles/variables.css`, `src/styles/components.css`, `src/styles/global.css`, `src/styles/responsive.css` — палитра и стили.
- `src/utils/animations.js` — фирменный цвет пиксельных эффектов.
- `index.html` — метаданные направления выездного сервиса.

## Ограничения проверки

Проверены синтаксис JavaScript, относительные импорты, рендер компонентов и разбор CSS. Установка Vite в изолированной среде завершилась по тайм-ауту, поэтому production build здесь не подтверждён. После распаковки проекта необходимо выполнить `npm ci` и `npm run build` локально.


## Final supplied logo asset

The exact user-supplied 107×107 PNG mark is stored at `public/logo-mark.png`. `public/logo.svg` uses this image unchanged beside the Goulash.tech wordmark, and `index.html` uses the same PNG as the favicon. The former approximate hand-drawn SVG mark is no longer used.
